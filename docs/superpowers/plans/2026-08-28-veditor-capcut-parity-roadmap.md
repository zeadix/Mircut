## 0. 现状与差距总览

## 1. 阶段一 P0：剪辑硬伤(对标门槛)

### 1.1 关键帧曲线编辑器 + 关键帧动画导出
**目标**：从"三选一插值"升级为可视化贝塞尔曲线编辑；关键帧动画真正导出到成片(目前 export 仅取首帧值，逐帧动画缺失)。

**技术落点**：
- `core/fx.rs`：`Interpolation` 增加 `Bezier(c1: f64, c2: f64)` 变体；`Animatable::value_at` 支持贝塞尔(用三次贝塞尔求 y(t))。
- `export`：视频/音频属性(不透明度/缩放/位移/音量)逐帧动画，用 FFmpeg `sendcmd` 或分段 `enable` 表达式；先支持不透明度(核心)、音量。
- `frontend/Inspector`：关键帧列表 + 每条关键帧可展开的贝塞尔控制点拖拽控件(SVG 绘制曲线 + 手柄)。

**任务**：
- [ ] core: Bezier 插值 + value_at 求值 + 单测
- [ ] export: 不透明度关键帧 → `fade`/`sendcmd` 逐帧导出 + 端到端单测
- [ ] frontend: 曲线编辑器组件 + 关键帧时间轴定位

**验收**：拖拽关键帧手柄改曲线，导出后画面按曲线渐隐(像素级验证)。

### 1.2 蒙版(线性/圆形/矩形/镜像)
**目标**：片段支持蒙版，蒙版形状/位置/羽化可关键帧动画。

**技术落点**：
- `core/fx.rs`：`Mask { kind, x, y, w, h, feather, invert, keyframes }`。
- `export`：FFmpeg 蒙版用 `geq`(像素表达式生成 alpha)或 `drawbox`+`colorkey` 组合；优先实现矩形/线性蒙版(最常用)。
- `render`：预览用 Canvas `clip()` + `globalCompositeOperation` 近似。

**任务**：
- [ ] core: Mask 模型 + 序列化 + 单测
- [ ] export: 矩形蒙版(drawbox 反选)+ 线性蒙版(geq 渐变 alpha)+ 端到端验证
- [ ] frontend: Inspector 蒙版区(形状切换 + 参数滑杆)

**验收**：矩形蒙版导出后画面仅显示蒙版区域，预览与导出一致。

### 1.3 混合模式
**目标**：画中画/文字叠层支持正片叠底/滤色/叠加/柔光等混合模式。

**技术落点**：
- `core/fx.rs`：`BlendMode` enum 挂 `ClipFx`。
- `export`：FFmpeg `blend=all_mode=...` 滤镜。
- `render`：Canvas `globalCompositeOperation` 映射。

**任务**：
- [ ] core: BlendMode 枚举 + 序列化
- [ ] export: blend 滤镜映射 + 单测
- [ ] frontend: 混合模式下拉

**验收**：画中画片段切"正片叠底"，导出叠加效果正确。

### 1.4 预设滤镜库
**目标**：一键滤镜(电影感/日系/胶片/黑白/复古/冷调等)，降低调色门槛。

**技术落点**：
- `core` 或 `export`：预设 = `ColorGrade + 可选 LUT` 组合，定义常量表。
- `frontend/Inspector`：预设下拉 + 预览缩略图(对当前帧应用预设后的小图)。

**任务**：
- [ ] export: 预设常量表(≥10 种) + 单测
- [ ] frontend: 预设下拉 + 应用

**验收**：选"电影感"一键改变片段调色，可撤销。

### 1.5 文字花字/动画预设
**目标**：富文本样式(描边多级/阴影/渐变花字)+ 入场/出场/循环动画。

**技术落点**：
- `core/fx_ext.rs`：`TextOverlay` 扩展阴影、渐变色、描边宽度、动画类型。
- `export`：drawtext 多描边/阴影参数 + 动画用位置表达式(`x`/`y` 随 `t` 变化)。
- `frontend/TextPanel`：样式控件 + 动画预设下拉。

**任务**：
- [ ] core: TextOverlay 字段扩展 + 序列化
- [ ] export: drawtext 阴影/渐变 + 动画表达式 + 单测
- [ ] frontend: 文字面板样式区

**验收**：文字带阴影+渐变+入场动画，导出烧录正确。

## 2. 阶段二 P1：AI 与专业能力

### 2.1 人像 AI 抠像
**目标**：本地人像分割(不依赖绿幕)。

**技术落点**：
- `ai`：接 ONNX Runtime(`MODNet`/`BiRefNet`)或 CLI(`rembg`)，逐帧出 alpha 序列到缓存。
- `export`：视频 + 预生成 alpha 序列 → `alphamerge`。
- 降级：无模型/无引擎时提示下载或退回绿幕抠像。

**任务**：
- [ ] ai: 引擎探测 + alpha 序列生成接口 + 测试
- [ ] export: alpha 序列合并导出
- [ ] frontend: 抠像区"AI 人像"开关

**验收**：有人物视频开启 AI 抠像后背景透明，导出叠加到底层。

### 2.2 AI 智能分割
**目标**：长视频按场景/镜头自动切分。

**技术落点**：
- `ai`：场景检测(接 `PySceneDetect` CLI 或 ffmpeg 帧差值直方图)。
- 复用现有 `SplitClip`，按检测时间点批量分割。

**任务**：
- [ ] ai: 场景检测接口 + 测试
- [ ] app: 分割点 → 批量 split 命令(可撤销)

**验收**：长视频一键切出场景片段，时间轴出现分段。

### 2.3 图文成片(脚本→成片)
**目标**：输入文案脚本，生成分镜→TTS 配音→字幕→时间轴。

**技术落点**：
- 复用已有 TTS + 字幕轨 + 项目模型；新增"脚本解析 → 段落 → 每段配音+字幕块"流水线。
- `app`：`script_to_timeline(script)` 命令，串行生成。

**任务**：
- [ ] app: 脚本解析 + 段落切分
- [ ] app: 每段 TTS 生成音频块 + 字幕块(时间对齐)

**验收**：粘贴文案 → 一键生成含配音+字幕的时间轴。

### 2.4 响度标准化 / 自动增益
**目标**：多轨混音后统一响度(如 -14 LUFS)。

**技术落点**：
- `media`/`export`：ffmpeg `loudnorm`(导出时对最终混音应用)。

**任务**：
- [ ] export: loudnorm 滤镜 + 单测

**验收**：导出音频响度归一，跨视频一致。

### 2.5 人声分离
**目标**：提取人声/伴奏。

**技术落点**：
- `ai`：接 `demucs`/`UVR` CLI，分离后分别落音频块。

**任务**：
- [ ] ai: 分离引擎探测 + 接口
- [ ] app: 分离结果生成人声/伴奏两个音频块

**验收**：一首歌分离出人声和伴奏两条音轨。

### 2.6 一键发布
**目标**：直传 B站/抖音/视频号。

**技术落点**：
- 需账号 OAuth，本地实现成本高；先做"导出到平台预设 + 打开上传页"，账号直传列为远期。

**任务**：
- [ ] 先做平台预设补全 + 导出后跳转网页上传(降级方案)

**验收**：导出后一键打开对应平台上传页。

## 3. 阶段三 P2：生态与协作(远期)

| 能力 | 说明 | 备注 |
|---|---|---|
| 数字人/智能口播 | 本地数字人成本极高 | 可先接第三方 |
| 云同步/多端 | 需服务端 | 远期 |
| 素材/模板市场 | 社区贡献 + 格式开放 | 依赖插件化 |
| 音频录制 | 声卡输入录音 | 依赖音频设备 API |

## 4. 阶段四：差异化壁垒

### 4.1 Linux 打包完善
- AppImage/Flatpak/deb/rpm 全量 + CI 自动发布；解决 FFmpeg 运行时依赖(自带或动态链接)。

### 4.2 插件化体系(核心差异化)
- 滤镜/转场/蒙版/特效做成**可注册插件**：定义 trait + 注册表，第三方可写 Rust 插件或描述文件(JSON)声明 FFmpeg 滤镜链 + 预览参数。
- 为社区素材生态铺路。

### 4.3 性能持续优化
- 预览引擎从代理帧升级为实时解码管道(已有 RealtimeRenderer 基础，继续完善 GPU 合成)。

---

## 5. 建议执行顺序(依赖关系)

```
阶段一(全部可并行/顺序)→ 阶段二 AI 能力 → 阶段四差异化 → 阶段三生态
具体：1.1 曲线编辑器(先打通关键帧导出) → 1.2 蒙版 → 1.3 混合模式 → 1.4/1.5 预设库
      2.1 AI 抠像 → 2.2 分割 → 2.3 图文成片 → 2.4/2.5/2.6
      4.2 插件化(依赖阶段一各能力成型后)
```

## 6. 风险

| 风险 | 对策 |
|---|---|
| FFmpeg 蒙版/混合模式滤镜与预览一致性难保证 | 先做矩形/线性蒙版 + 常用混合模式，逐项端到端验证 |
| 关键帧动画导出复杂度高(逐帧/sendcmd) | 先支持不透明度+音量，再扩缩放/位移 |
| AI 模型(ONNX/whisper)体积与分发 | 模型按需下载，CLI 探测降级 |
| 一键发布需账号 OAuth | 先做"导出+跳转网页上传"降级 |
| 插件化过度设计 | 用描述文件(JSON)最小可行，不做动态加载 DLL |
