# 文件轨道重新设计规格

- **日期**: 2026-09-01
- **状态**: 已确认（设计方案通过）
- **功能**: 文件轨道三行结构与整体拖拽交互

## 1. 概述

重新设计文件轨道组件，采用三行结构（时间 + 视频 + 音频），文件块竖跨三行并作为整体进行拖拽和调整操作。

## 2. 设计决策

| 决策点 | 结论 |
|---|---|
| 轨道结构 | 三行：时间行、视频行、音频行 |
| 轨道类型 | 只保留文件轨道（移除纯 Video/Audio 轨道的 UI） |
| 文件块 | 竖跨三行，内部三块不可单独拖拽 |
| 时间调整 | 拖拽左右边缘，整体同步调整（视频和音频时长联动） |
| 素材拖放 | 插入模式，自动推开后面内容 |
| 交互反馈 | 悬停边框变深、选中高亮+手柄、拖拽半透明 |
| 视频/音频控制 | 可单独关闭视频或音频（灰色禁用状态） |

## 3. 文件块内部设计

### 3.1 时间块（详细模式）

显示内容：
- 入点时间（如 `入 00:05`）
- 出点时间（如 `出 00:15`）
- 总时长（如 `| 10s`）

布局：水平排列，左侧入点出点，右侧时长

### 3.2 视频块（精简模式）

显示内容：
- 3-5 个缩略图均匀分布（缩略图胶片效果）

布局：等宽分布，占满整个视频块宽度

### 3.3 音频块（详细模式）

显示内容：
- 波形图（SVG 路径绘制）
- 音量指示（如 `Vol: 80%`）

布局：波形占满宽度，音量指示在右上角

## 4. 交互状态

### 4.1 悬停状态
- 边框颜色变深（从 `#0071e3` 到 `#5a5a5a`）
- 无其他视觉变化

### 4.2 选中状态
- 边框高亮为 `#0071e3`
- 阴影加深：`box-shadow: 0 2px 8px rgba(0,113,227,0.3)`
- 左右边缘显示调整手柄（6x12px 蓝色方块）

### 4.3 拖拽中状态
- 整体半透明：`opacity: 0.7`
- 阴影加深：`box-shadow: 0 4px 16px rgba(0,0,0,0.2)`
- 可添加轻微位移效果（如 `transform: translateX(4px)`）

## 5. 技术实现要点

### 5.1 数据结构

```typescript
// 文件块（Clip）保持原有结构，lane 字段不再需要
interface Clip {
  id: string;
  track_id: string;
  start: number;      // ticks
  duration: number;   // ticks
  asset: AssetRef;
  video_on: boolean;  // 视频是否启用
  audio_on: boolean;  // 音频是否启用
  // ... 其他字段
}

// 轨道类型统一为 File
interface Track {
  id: string;
  kind: "File";
  name: string;
  locked: boolean;
  hidden: boolean;
}
```

### 5.2 渲染架构

文件轨道渲染为三行高度：
- `geo.rowH` 数组包含三行高度：`[timeRowH, videoRowH, audioRowH]`
- 文件块绘制时作为一个整体 `rect`，内部再用分隔线或色块区分三个区域

### 5.3 拖拽逻辑

- `DragSession` 中 `move` 类型整体移动文件块
- `trimL`/`trimR` 同时调整视频和音频的 `source_in`/`source_out`
- 不再区分 video lane 和 audio lane 的独立拖拽

### 5.4 素材拖放

`DropTarget` 结构简化：
```typescript
interface DropTarget {
  trackId: string;
  start: number;  // ticks
  // 不需要 lane 字段
}
```

## 6. 视觉效果规格

| 元素 | 规格 |
|---|---|
| 文件块边框 | 2px solid `#0071e3` |
| 文件块圆角 | 6px |
| 时间块背景 | `#f5f5f7` |
| 视频块背景 | 渐变 `#e8f4fd` -> `#d4e8fa` |
| 音频块背景 | 渐变 `rgba(52,199,89,0.1)` -> `rgba(52,199,89,0.2)` |
| 波形颜色 | `#34c759` |
| 分隔线 | 1px solid `#d1d1d6` |

## 7. 独立控制

当 `video_on = false` 时：
- 视频块显示灰色禁用状态
- 视频内容不参与合成

当 `audio_on = false` 时：
- 音频块显示灰色禁用状态
- 音频内容不参与合成

## 8. 兼容性

- 保留现有 Video/Audio 轨道的 Rust 数据结构
- 仅移除 UI 层面的独立轨道渲染
- 新建项目默认使用文件轨道
- 旧项目打开时，纯 Video/Audio 轨道自动转换为文件轨道（如果技术上可行）或保持兼容
